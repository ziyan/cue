# Plans

A plan is a design document written before the work, kept up to date during it,
and moved to `../done/` when it lands. It is written so that somebody who has
only this repository and this file can carry the work on, which means defining
its terms and saying why rather than only what.

`docs/decisions/` is for a single choice and is immutable once merged. A plan
is a living document and covers a body of work.
